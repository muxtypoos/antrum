# Antrum – Gastric POCUS Decision Tool

A free, offline decision-support tool for bedside gastric ultrasound (POCUS). Live at **https://muxtypoos.github.io/antrum/**

## How to use
1. Enter the patient's age (and weight, if known). For under 18s, switch on Paediatric mode, which needs both.
2. Scan supine, then right lateral decubitus (RLD), and pick the finding that matches each view.
3. If clear fluid is seen, measure the antral cross-sectional area (CSA) and enter it.
4. The result (SAFE or UNSAFE, with empty or full stomach) appears under the steps and in the top bar.

Works on phones, tablets and computers. Once loaded, it needs no internet connection.

## Important
This tool supports, and does not replace, clinical judgement. Gastric ultrasound alone should not decide induction technique: use it with the clinical situation, local policy and appropriate training. Not a regulated medical device.
